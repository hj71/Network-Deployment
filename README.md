# Network-Deployment

公开的网络、系统与服务部署技术知识库。仓库中的公开资料均经过脱敏处理；实际设备、接口、地址、日志和个人环境证据保存在独立私有仓库中。

## 项目导航

| 项目 | 内容 | 状态 |
|---|---|---|
| [mac-clash-gateway](mac-clash-gateway/) | Mac Internet Sharing + PF + Clash Verge Rev/Mihomo 旁路由 | Production Baseline v1.0 |

## 分类规划

- `mac-clash-gateway/`：macOS 旁路由部署与恢复
- `cloudflare/`：Cloudflare 服务和边缘部署
- `ai-services/`：AI 服务、模型网关与知识系统
- `linux/`：Linux 服务与网络部署
- `assets/`：全站共用图片和图表

## 仓库约定

- 一个技术项目使用一个稳定的英文目录名。
- 每个项目提供自己的 `index.md`、`README.md`、版本记录、文档和脱敏配置。
- 根目录只维护全站导航和 GitHub Pages 配置。
- 不公开密码、令牌、私钥、订阅地址、实际设备标识或未脱敏日志。
