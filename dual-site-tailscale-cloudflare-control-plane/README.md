# 项目说明

本目录是公开博客文章的源文件。文章讲述基于 Tailscale 连接家庭和办公室两个站点，并以 Cloudflare Worker 与 D1 建立独立观察、诊断协调和受控操作通道的实践。

文章入口：[用 Tailscale 连接家庭与办公室：双 NAS 网关与 Cloudflare 独立管控平面](index.md)。

配套代码包发布于 [GitHub 仓库](https://github.com/hj71/dual-site-tailscale-cloudflare-control-plane)，版本为 [v0.1.0](https://github.com/hj71/dual-site-tailscale-cloudflare-control-plane/releases/tag/v0.1.0)。公开代码仅为经过脱敏的历史参考实现，不是可直接安装的生产包。

正文使用虚构设备名和地址。真实故障触发后的完整自动恢复链路尚未验收。
